# System

An offline, local-only record for a plural system. Members, who's fronting,
front history, relationships, roles, and a "void" for dormant alters.

**No account, no server, no sync, no analytics.** Everything you enter is
stored in your own browser on your own device and is never transmitted
anywhere. There is no backend for it to be transmitted *to*.

Open it once over https and it installs to your home screen and works
with no signal from then on.

Export writes a plain JSON file you can read, keep, and import back.
Built because an app people relied on shut down and took their history
with it.
